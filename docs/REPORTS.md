\# Gemini Playground - Telemetry \& Reports Schema



This document defines the official data schemas for all logs and reports generated by the Gemini Playground system. All telemetry modules (e.g., `audit.js`, `report.js`) must conform to these structures.



\## 1. AI Usage Log (`/logs/ai\_usage.log`)



\* \*\*Purpose:\*\* Logs metadata for \*every\* call to the `aiService.generate()` function for billing, rate-limiting, and performance tracking.

\* \*\*Format:\*\* One JSON object per line (newline-delimited JSON).

\* \*\*Reference:\*\* Spec 4.2.1, 8.6



\### Schema Definition



```json

{

&nbsp; "type": "object",

&nbsp; "properties": {

&nbsp;   "timestamp": {

&nbsp;     "description": "ISO 8601 timestamp of when the request was initiated.",

&nbsp;     "type": "string",

&nbsp;     "format": "date-time"

&nbsp;   },

&nbsp;   "provider": {

&nbsp;     "description": "The AI provider used for the final successful response.",

&nbsp;     "type": "string",

&nbsp;     "enum": \["gemini", "openai", "anthropic", "custom"]

&nbsp;   },

&nbsp;   "model": {

&nbsp;     "description": "The specific model used (e.g., '1.5-flash', 'gpt-4o').",

&nbsp;     "type": "string"

&nbsp;   },

&nbsp;     "description": "Total duration of the API call in milliseconds.",

&nbsp;     "type": "integer"
